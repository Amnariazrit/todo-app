# Next.js Development Skill

## Overview
This skill provides comprehensive assistance for Next.js development tasks, including component creation, routing, API routes, styling, performance optimization, and best practices.

## Capabilities
- Create Next.js components with TypeScript
- Implement Next.js 13+ App Router patterns
- Set up API routes and server-side rendering
- Apply modern styling solutions (Tailwind CSS, CSS Modules)
- Optimize performance and implement best practices
- Handle data fetching and state management
- Configure Next.js settings and environment

## Component Creation
When creating React components for Next.js applications:
- Use functional components with TypeScript interfaces
- Follow Next.js App Router conventions (`app/` directory)
- Implement proper prop types and validation
- Include necessary imports from 'react' and 'next'

## File-Based Routing
- Utilize the App Router (`app/`) for new projects
- Create route segments using folder structure
- Implement loading states, error boundaries, and not-found handlers
- Use route groups and parallel routes when appropriate

## Styling Guidelines
- Prefer Tailwind CSS for utility-first styling
- Use CSS Modules for component-scoped styles
- Leverage Next.js Image and Link components
- Implement responsive design patterns

## Data Fetching
- Use `async`/`await` for server-side data fetching
- Implement `fetch` with appropriate caching strategies
- Handle loading and error states properly
- Follow SSR, SSG, and ISR best practices

## Performance Optimization
- Implement code splitting with dynamic imports
- Optimize images using Next.js Image component
- Use React.memo for component memoization
- Implement proper key props for lists

## Best Practices
- Follow Next.js conventions and file structure
- Use TypeScript for type safety
- Implement proper error handling
- Maintain clean, readable code
- Follow accessibility guidelines
