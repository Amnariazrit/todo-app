# Todo App Project

This project contains a multi-phase Todo application development, showcasing progression from a simple console app to a full-stack web application.

## Project Structure

### Phase I - Console Todo App (`PhaseI/`)
A command-line Todo application built with Python featuring:
- Add, view, update, delete, and mark complete operations
- In-memory storage
- Clean CLI interface

### Phase II - Fullstack Todo App (`PhaseII/`)
A complete web application with:
- React frontend (`PhaseII/frontend/`)
- FastAPI backend (`PhaseII/backend/`)
- User authentication
- Multi-user support
- Full CRUD operations

## Phases

### Phase I: Console Application
- Built with Python
- Command-line interface
- In-memory storage
- Basic task management features

### Phase II: Full-Stack Application
- Frontend: React with Vite
- Backend: FastAPI with SQLModel
- Database: PostgreSQL (with SQLite for local development)
- Authentication: JWT-based
- Responsive web interface

## Getting Started

### Phase I
1. Navigate to `PhaseI/`
2. Run commands like: `python main.py add "New task"`

### Phase II
1. Backend: Navigate to `PhaseII/backend/`, install dependencies and run server
2. Frontend: Navigate to `PhaseII/frontend/`, install dependencies and run development server
